# Portafolio · Carolina Zapata

Sitio de una sola página: todo está en `index.html` (Home, Inicio, Sobre mí, Proyectos, Contacto y las 3 páginas de proyecto).
No necesita instalar nada.

## Archivos
- `index.html`: el sitio completo.
- `img/`: fotos y logos.

## Cómo funcionan las páginas de proyecto
Cada franja de Proyectos abre su página dentro del mismo `index.html`:
`#proyecto-arego`, `#proyecto-alicia` y `#proyecto-concepto`.
Se cierran con el número grande (01, 02, 03), con la tecla Esc o con el botón "Atrás" del navegador.

## Imágenes
Si quieres cambiar una foto, reemplázala **con el mismo nombre de archivo** dentro de `img/`.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube **todo** el contenido de esta carpeta (`index.html` en la raíz, junto a la carpeta `img`).
3. En Settings → Pages elige "Deploy from a branch", rama `main`, carpeta `/ (root)` y guarda.
4. En unos minutos tu sitio estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
